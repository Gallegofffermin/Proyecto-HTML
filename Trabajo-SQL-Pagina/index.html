Mini Guía SQL

¿Qué es SQL?

SQL (Structured Query Language) es un lenguaje utilizado para trabajar con bases de datos relacionales.

En una base de datos relacional, la información se organiza principalmente en tablas. Estas tablas están formadas por columnas y filas.

Las columnas representan los campos o características de los datos, mientras que las filas representan los registros almacenados.

Tabla

Es donde se almacenan los datos de una determinada entidad o tema.

Registro

Es una fila de la tabla que contiene los datos correspondientes a un elemento.

Campo

Es una columna que representa una característica de los registros.

Ejemplo de una tabla

Una tabla de personas podría tener la siguiente estructura:
