Consultas SQL

Una introducción a las consultas y al manejo de registros.

¿Qué son las consultas?

Las consultas son una de las principales formas de obtener información de los registros almacenados en las tablas.

Mediante SQL podemos seleccionar determinados campos, filtrar registros y ordenar los resultados.

Creación de registros

INSERT INTO se utiliza para agregar nuevos registros a una tabla.

Primero indicamos el nombre de la tabla y los campos que queremos completar. Luego, mediante VALUES, indicamos los valores correspondientes. 

INSERT INTO personas
    (id, nombre, dni, fecha_nacimiento)
VALUES
    (1, 'Jorge Alberdi', 11384726, '1965-03-17'),
    (2, 'Marcos Zidane', 14306718, '1968-09-04');

SELECT

SELECT permite indicar qué campos queremos obtener de una tabla.

Una consulta básica puede seguir esta estructura: 

SELECT campo_a, campo_b
FROM tabla
WHERE campo_a condicion
ORDER BY campo_b ASC;

Tabla de ejemplo

Supongamos que tenemos una tabla llamada personas:

ID Nombre DNI Fecha de nacimiento
1 Jorge Alberdi 11384726 1965-03-17
2 Marcos Zidane 14306718 1968-09-04

WHERE

WHERE permite establecer una condición para filtrar los registros que queremos obtener. 

SELECT nombre, dni
FROM personas
WHERE dni > 12000000;

En este caso solamente se obtendrán las personas cuyo DNI sea mayor a 12000000.

ORDER BY

ORDER BY permite ordenar los resultados de una consulta.

Podemos utilizar ASC para ordenar de forma ascendente o DESC para hacerlo de forma descendente. 

SELECT nombre, dni
FROM personas
WHERE dni > 12000000
ORDER BY nombre ASC;
