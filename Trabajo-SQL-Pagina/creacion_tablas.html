Creación de tablas

Una introducción sencilla al lenguaje SQL y a las bases de datos relacionales.

¿Cómo se crea una tabla?

Para crear una tabla primero tenemos que entender dos cosas:

  1. La sintaxis de CREATE TABLE.
  2. Los tipos de datos de los campos.

En esta guía veremos ambos conceptos de manera sencilla.

Tipos de datos

El tipo de dato indica qué clase de valor puede almacenar un campo de una tabla.

Tipo Descripción Ejemplo
INT Números enteros. 25
DECIMAL Números con decimales. 125.50
BOOLEAN Valores verdadero o falso. TRUE
VARCHAR Texto de longitud variable. Jorge
DATE Fechas. 1965-03-17

Longitud de los campos

Algunos tipos de datos permiten especificar información adicional utilizando paréntesis.

Por ejemplo: 

VARCHAR(100)

indica que el campo puede almacenar hasta 100 caracteres.

DECIMAL

En el caso de DECIMAL, los números dentro de los paréntesis indican la precisión y la cantidad de decimales. 

DECIMAL(5,2)

El primer número indica la cantidad total de dígitos y el segundo indica cuántos corresponden a la parte decimal.

Por ejemplo, se pueden almacenar valores como:

  • 123.45
  • 12.50
  • 999.99

Sintaxis de CREATE TABLE

La sintaxis básica para crear una tabla es: 

CREATE TABLE nombre_tabla (
    nombre_campo tipo_dato parametros,
    nombre_campo tipo_dato parametros
);

Podemos dividir esta estructura en varias partes:

  • nombre_tabla: nombre que tendrá la tabla.
  • nombre_campo: nombre de una columna.
  • tipo_dato: indica qué tipo de información almacenará.
  • parametros: características adicionales del campo.

Ejemplo completo

Podemos utilizar estos conceptos para crear una tabla de personas: 

CREATE TABLE personas (
    id INT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    dni INT NOT NULL,
    fecha_nacimiento DATE
);

PRIMARY KEY

Una PRIMARY KEY identifica de manera única cada registro de una tabla. 

id INT PRIMARY KEY

NOT NULL

NOT NULL indica que un campo no puede quedar vacío. 

nombre VARCHAR(100) NOT NULL
